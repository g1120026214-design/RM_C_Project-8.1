# 11月7日 代码规范培训任务

#### 项目简介：

基于STM32-FreeRtos的一个多功能控制系统 

##### 

##### 项目功能：

1.通过串口发送“motor+100”让gm6020电机以100rpm的转速稳定旋转 并每2s发送一次当前转速
2.发送“motor0”停止旋转和速度发送
3.每按一次按键让舵机旋转20°
4.检测C板状态 电机在线时亮绿灯 电机离线则红灯以2s为周期呼吸



##### 硬件环境：

单片机：STM32F407

开发板：大疆RoboMaster开发板C型

##### 软件环境：

STM32CubeMx Hal库

###### PS:项目中使用GM6020电机ID为0x205 如电机ID不同应去main.c函数里修改电机ID宏定义参数
